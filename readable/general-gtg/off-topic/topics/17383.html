Okay so long story short I don't really like how vague and void of information the game pokedexes are. In the anime and movies the pokedex has been known to supply useful info on moves and Pokemon (when people like Brock aren't doing it for the pokedex) but in the games: none! Nada! So I decided to make a fanon online pokedex containing actual info on the Pokemon based on info collected from the anime, manga, games, and all other forms of Pokemon media. And the Pokedex wouldn't be censored either. It would actually talk about how Pokemon prey on each other and could definitely kill you. This dex would also contain information that can be assumed and isn't found in any games or stories and false accounts from fictional non-canon people. Now here's the catch. I need help (I also don't know where to put the site so I need suggestions for platforms that can host the site (that don't cost anything. Unless someone else wants to host the site for me i guess.)) doing this because there are over 800 Pokemon so I can't do it alone. I can take care of some articles but definitely not all. And that's not even covering the info on regions and items and organizations and the like I plan on adding. So... Anyone want to help?

*----------+----------*
​
To clarify a few things: this is very much a "patchwork fic" in that it uses fanon to fill in the holes where canon doesn't make sense. it is taken from a very realistic stand point in that Pokemon can very much maul you to death and Pokemon very much prey on each other. It also features details on stuff such as items, towns, organizations, regions and the like. And the answer is yes: sonic the hedgehog is now sonic the sandslash in this universe but for the love of god don't mention the actual name of any existing franchise or a parody name of any franchise because I don't like getting sued. Also it looks professional.
