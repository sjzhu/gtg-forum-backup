Here's my assessment:

 

Environments: 4EE, 2RC, 2IR, 2ST, 2VE, 2WC, Gulch, Final, OIV = 17

Vengeance Villains: 5 choose 5 (1) + 5 choose 4 (5) + 5 choose 3 (10) = 16

Villains: 16 + 4EE,4RC,4IR,4ST,4WC, Ambuscade, Kismet, Wager = 39

Heroes: 10EE,2RC,2IR,2ST,5VE,2WC, Unity,Scholar,TO BE NAMED = 26

unique 3-player Hero combinations: 26 choose 3 = 26!/(3!23!) = 262524/32 = 26254=26*100= 2,600

unique 4-player Hero combinations: 26 choose 4 = 26!/(4!22!) = 26252423/432 = 262523=14,950

unique 5-player Hero combinations: 26 choose 5 = 26!/5!21!) = 2625242322/5432=26523*22=65,780

1739(2,600 + 14,950 + 65,780)= 55,247,790

This does not include promos. If we allow multiple versions of the same hero to be played in the same game, the number is as easy to calculate, but if we don't, the calculation is more complex. I worked out the equations for that once, but it was before there were heroes that had multiple promo cards. I'm not up to figuring out the details now that Wraith, Legacy, Bunker, Haka, Tempest, and Fanatic are sporting double promos. The promo villains are easier to include, as they simply increase the number of villains.

Imagine you only have the core game and you only ever play with four heroes:

 

4 villains * 4 environments * 10 choose 4 heroes = 16 * 10!/6!*4! = 16*10*9*8*7/4*3*2 = 16*10*3*7 = 3,360

 

Can you imagine ONLY having 3,360 ways to play the game? 

 

Now imagine that all you care about is getting to play each hero against each villain plus each hero in each environment:

10*4 + 10*4 = 80

 

Geez, only 80 different ways to play the game. That's barely 79 ways more than Settlers of Catan.
