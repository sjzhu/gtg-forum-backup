Love it.I've already made a full set of Insula Primalis tiles and about half a set of Megalopolis tiles, back when all we got for playtesting were tiles with blocks of color on them.  I used basic Photoshopping skills, plus some 3D models from Google's Sketchup (the app that lets anyone make 3D models for their maps) and some Dundjinni top-down art assets for things like trees and cars.  It's not that hard, and I expect to see a whole raft of custom tiles from fans once the game comes out.

Here is a file with tutorial that allows people to make custom Sentinel tactics environment tiles using the freeware program Inkscape. To use it, unpack the file using Winrar or Winzip, download and install Inkscape and open the file. In this version I estimated the size of the tiles to be 150mm and can adjust that easily if the size varies from that. The .rar file also contains the printscreen from google maps that was used for the earlier posted example, so as to provide some practice material. Enjoy!
