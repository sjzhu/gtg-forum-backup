If only it developers could write once and run everywhere (stupid Java promise).  Unfortuantly it's not that easy.  While each platform can share assets (sounds, arts, maybe a cross-platform SDK), the code still needs to be ported and tested, which costs time and money.  I was impressed that they got both iPad and Android out at the same time.  I was more impressed when they released a steam version that worked on PC and Mac (and soon Linux).  That's five different platforms alone that they have to maintain, not counting the different versions (iOS 8.0, 8.01, 8.1), Android (Honeycomb, ICS, Jelly Bean, KitKat, Lollypop...Man I'm hungry), Windows (7,8, 8.1), OS X (Mavericks, Yosemite), and Linux (too many distros to name).  It's not an easy process to develop for.

Then there are some store agreements (*cough* Apple *cough*) that can have specific language in their guidelines that prevent cross-platform purchase sharing or allows purchases on other platforms to transfer.

In the end, I can't imagine the numbers would add up for them to set up a central server that tracks and somehow gives access to every expansion purchased on every platform a person owns.  I think Google and Apple takes 30% off the top.  I'd guess Steam does the same (and offers you all supported platforms, further cutting into Handelabra revenue).  Then they probably have a license fee with >G.  It all adds up.  I can't talk for Handelabra, but I can assume they want to make at least little bit of money :-).

Ben
