I doubt they can interact using the new built in iOS feature allowing communications between iOS devices.  However, there is a protocol known as AllJoyn which is supposed to allow computers and devices communicate with each other, reguardless of the operating system running (so long as the AllJoyn framework has been ported to that operating system), and without need for an internet connection (such as bluetooth or WiFi Direct or whatever).
