I agree that if there's only one hero in the game then there is no second-lowest hero to take the damage.  This would (IMO) be just like KNYFE's "Infiltrate and Obfuscate", which redirects damage to the villain target with the second-highest hp.  It's been officially ruled that if there is not a villain target with the second-highest hp (i.e. there's only one villain target in the game), then the redirection can't happen.
