In the contexts in which you see that text the most, it means this:

Each turn (meaning, the villain turn, the environment turn, or each one of the hero turns), the first time something happens, do what the card says to do.  If it happens again during the same turn, don't trigger it again, but if it happens again on a following turn, you should trigger it.

For example, "the first time this card takes damage each turn, do XYZ" means that if Haka plays a one-shot that damages the card, XYZ will happen.  But if Haka then activates a power on that same turn that also does damage, XYZ is not triggered.  However, when it's the next hero's turn, you'll be checking for the first time the card takes damage again.

A round is a full trip around the table (villain, all heroes, environment).  A turn is each part of that.

Hope that makes sense.

That text happens the first time each turn the relevant event occurs.  It would happen every turn if it were triggered every turn, but only the first time.

Does that answer your question?
