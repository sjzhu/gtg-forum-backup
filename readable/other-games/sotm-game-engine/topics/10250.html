The best option is to use the unselected heroes as a "sidekick deck", where you have access to a different incapacitated power each turn. See here:

http://www.boardgamegeek.com/thread/872326/my-journey-to-find-the-best-rules-for-a-2-players

 

Otherwise, playing a 3 hero game while running 2 of the complexity 1 heroes (Legacy + Wraith together aren't nearly as complicated as Absolute Zero is alone) can be a viable alternative, even for new players.
