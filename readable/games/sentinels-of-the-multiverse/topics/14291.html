…They are. Gahh. Dammit Chris, stick to your guns!

Let's think about this. Currently, when picking a team, we start off with every possibility, then for each hero chosen we reduce the possibilities for the next choice by 1 + (the average number of promos per hero). That doesn't work here, because rather than just having one hero and a bunch of promos, the promos can mix and match. It's a different interaction between heroes and promos. So, short of calculating (for each team size) the chance of someone picking The Sentinels team, and then using a different calculation accordingly, we're stuck.

Except that's thinking of things literally, not mathematically. What we actually have is a large set of options (of every possible variant of every hero) which are bundled into smaller groups (of each hero + their promos, generally), where choosing any option removes the whole group from the option space. The same still applies with The Sentinels; there are so many possible options in the "Sentinels Team" group, and once you choose one you remove the group. We're already averaging out the size of each option group, so it's not really a problem if the size of any one group is different from the others (even drastically), as long as we're still constraining these choices to one group of a known number of options.

4 members, each with a variant choice, makes for 16 possible Sentinels Teams. For our purposes, this is no different from a single Hero with 15 variant cards. So all I need to do is revise my "for the purposes of" statement to:

  • For the purposes of this, The Sentinels team counts as 1 hero with 15 variants (16 possible team makeups).

And I think we're done? Maybe? Fingers crossed?

(A s a side note, someone mentioned that they'd want this to also include each team order possible; this actually already does that! This applies to Vengeance-style villain orders too, which is nice.)
