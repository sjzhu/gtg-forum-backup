If you clear the game's data, then the game's data is deleted. The Weekly One-shot collection is part of that data.

It's stored in a file with the game data, and if you back up the game data you can restore it. iOS has native support for backing up and restoring app data, and I think there are 3rd party apps to do it on Android. Or you can do it manually with a file manager.
