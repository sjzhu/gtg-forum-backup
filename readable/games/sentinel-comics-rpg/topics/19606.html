With "Hit the Deck," it is described as a Reaction, which makes sense why. As the description of Reactions reads, you only roll 1 die in order to keep the game flowing. However, in the description for "Hit the Deck," it is described as taking a basic Defend action outside of your turn, which seems to imply that you would roll a "basic Defend," which, according to its description, rolls the usual die pool of 3.

So which is it with Hit the Deck? Is it a 1 die roll or 3? If it is 1 die, which die do you roll for it? Just wondering, as I'm sure it has turned up in somebody's game, but I just want to handle it "legally."
