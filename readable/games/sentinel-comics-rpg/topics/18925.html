I am no expert ... but the way I understand it is that this game often relies more on plain english than keywords.  For games like D&D there are a set number of damage types, but in this game there is no set list. Thus when a game element mentions something that has no keywords associated with it then just use the narative descriptions to determine the effects.
In this case I interpet physical to be any solid objects, and energy as any "classical" energy types (lightning, heat, light... etc). Cosmic would be on the fence for me. The ony trope of comic books that perhaps would not count would be Pychic and Magic, but I am sure a group of clever players might find more.

Another example of this would perhaps be a classic werewolf, only silver weapons can harm it. No one has a silver attack, but armed with the knowledge, a hero might make a silver bullet, or silver hammer.
