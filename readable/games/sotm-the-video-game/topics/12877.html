I believe the answer to this is yes. If I remember correctly, MigrantP has stated that the game tracks the unlocks of Variants with two variables. If you unlock it with a code, itll fill in the variable that tells the game you used a code. If you unlock it legitimately, it fills in the variable that says you did the challenge. When the achievements are added, they'll look at the variable related to the challenges for confirmation of completion, which if you already did it should just auto-complete any achievements when you open up the game.
