A friend was playing Kismet in Insala Primalis. The Volcano came out, and they let it go off. When the game got to the Talisman, it did the damage and flipped it.

Then treated it like a new target: It did the damage and flipped it.

You see where this is going, right?

The game was stuck in an infinite loop. They had no way to get out of it, and it wasn't going to end on its own.

So yeah, I'd wouldn't recommend encountering Kismet on Insala Primalis. Apparently she can shatter timelines all by herself, there…

 

(I honestly think the game should treat the Talisman flipped as the same target that has just recovered the 7hp to avoid this, but not sure if that's how it is intended.)
