Hi. Not sure this is the correct forum but Ax0r at BGG suggested I post on this forum in relation to the Villain contest.

I've been working on some software, Forge of the Multiverse (FOTM), which is available at v0.1 and should be suitable for creating Hero and Villain decks. I'm working on other templates for v1.0 but dunno when I'll get them finished.

It's a java application packaged as an exe file and app for OS X. You need java 1.6 installed and you'll need to install the fonts in the fonts folder to work correctly (I'm working on loading these from files).

You can get it here for now but I'll upload to source forge or something later:

http://fostorial.webs.com/sotm/FOTM.rar

Here is an example of the output from the app. I used BakaMatt's Knock Out Gas card which was designed for the competition. Knocked it together in about a minute!

![Knock out gas](upload://iSRXNfXzCZ04aTsDATJyCrKfeKH.jpeg)

I've included the link to the original post but I would appreciate people trying it out, providing feedback and I'm happy to take feature requests. I've also included a couple of screenshots but the layout and fields may change over time.

http://boardgamegeek.com/thread/869145/sotm-card-creation-software-very-early-alpha-bui

EDIT 11/28/12: i found a way to change the color of the Quote bubble (simply find it in the FOTM image file, open it with GIMP, and change its color there; fortunately, it works retroactively on any cards you'ved created and saved when you re-open them!). so, i've removed that from the list below, though i would still recommend re-coloring it for future iterations of this software package. i've added the little bug about the "card text" box removing paragraph returns to the list.

@faust:

first, thanks for creating this card editor! it's a fun tool to have.

here are my suggestions to make it better:

1) be able to copy a card (not increase the number). this is so you don't have to edit every single field to get your cards to look the same when you want to use fonts and colors than the default ones. so frustrating!

2) be able to change the order of cards at will. so for example, if you create a new one-shot later for your deck, you can move it up to sit with the other one-shots.

3) might be nice if on the preview page, for the non-character cards, a preview of the card's text (or just the first few words) was one of the listed fields. also on this page, it would be nice if the preview picture of the card was at least large enough to read the text clearly.

4) finally, two fixes needed:

>>>a) when you choose "Export cards as PNG" they export as JPG and vice-versa. these somehow got mixed up. the "Export DECK as..." ones are fine though.

>>>b) when you save a deck , if you put paragraph returns between or before any text in the "card text" box, they are gone when you re-open it.

>>>c) you have templates for the Villain's HP card (front&back) but not for their Gameplay card (front&back needed for this too). the Gameplay card is actually more important since it tells you how to play with the Villain!

thanks! i'll be on the lookout for version 6!
