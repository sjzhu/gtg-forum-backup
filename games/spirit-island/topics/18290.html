Wilds only prevents the Explore action - it would have no effect on placing a Town due to an Event or Build, I'm afraid. The land with Wilds is just as valid a location as any other for your Town placement. Unless you meant Disease...in which case as far as I'm aware that still only blocks the Build action, so I think it would only get to prevent Town placement if the Event specifies "Invaders Build in X land", not just "add a Town to X land" or similar.
