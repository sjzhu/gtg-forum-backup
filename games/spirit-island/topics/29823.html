Welcome! Glad to have you join us!

It literally just replaces the spirit panels from Horizons with thicker panels. There’s nothing it will add to the game mechanically.

Some people really like the thick panels from the original game and wanted them for the Horizons spirits so that all their spirits would have the same type of panel.

If you’ve ever held the original spirit panels, you might prefer them over the thin panels. If you do, then this would be a good purchase, but if you don’t care it is definitely not needed. It’s just a replacement, what some would look at as an upgrade.

As for if it’s going to be available in retail or at cons, that’s a good question to send to the GTG folks at contact@greaterthangames.com.
