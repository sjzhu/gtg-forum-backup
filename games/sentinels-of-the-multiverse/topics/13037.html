Hi,

A few questions, that probably have obvious answers:

1. Unity basic power says, that I can destroy an equipment card to put mechanical bot into play. Does it have to be equipment that is in Unity play area, or from any hero play area?

2. Mechanical Bots are considered Hero Targets, or non-hero targets?

3. When the Environment card is dealing damage to a target with highest HP, can it target main Villain?

4. During Heroes turn, players can act in whatever order they want?

#2

1. Any hero equipment works for Unity's power.

2. Unity's bots are hero targets.

3. Yes, the Environment can choose the Villain for the target with the highest HP.

4. Each hero has a turn of his/her own, and they take those turns in order as set at the start of the game. One common way to do this is to start with the hero nearest to the villain, and then activate the other heroes going clockwise around the table.

 

I hope this helps.

1 - It doesn't specify that the equipment must come from Unity's deck, therefore you can destroy any card in play which has the "equipment" keyword.

2 - Any card in a hero deck is a hero card. Any card with hp is a target. Therefore a card with hp in a hero deck is a hero target :).

3 - If it just says it hits "the target with the highest hp" then yes, it can hit the villain if they have the highest hp. If it excluded villains it'd probably say "hero target".

4 - Turn order is decided at the start of the game and remains the same for the whole time (unless you're playing the Wager Master but his whole thing is messing with the rules). Villain always goes first, then heroes in the same order every time, then the environment.
