I thought it was time to start another event!!!

For this event, you will have a pool of 21 heroes to go up against 5 villains. You can divide the them any way you want, but each hero can only be used once. You decide if you use 3, 4, or 5 heroes for each match, and what order the heroes are in.

Only base versions of the heroes should be used, not variants.

In order to somewhat counteract the randomness of the draw, each match will be the best of 3 games. Please play the same set of heroes each time, but you may change their turn order between matches.

Please post your matches in this thread, as well as submitting them using this form. Please use this sheet to see a summary of the matches.

If you have any questions, please ask (or PM me).

Have fun!
