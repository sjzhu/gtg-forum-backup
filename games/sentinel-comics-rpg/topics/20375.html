In this case, the key word is 'size'. Max, Mid, and Min normally are used to refer to which die in the pool is being used for an effect. Since the ability states that it makes Max minions of size Min, we know that it make a number of minions equal to the Max die, determined as normal. Since it specifies the size of the Min die, once you determine the Min die, you use the die size of the Min die as the starting die size for the minions.
