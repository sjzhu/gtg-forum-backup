I don't think it should be consistent, personally. :-) 

Every situation will necessitate something different. We may want NPCs to address a challenge separate from the action, and in those situations it should be constructed in a way to make that moment as dramatic as possible (as we see in Infestation). In other situations, we might want to have them just aid the PCs in combat, in which case it should be specific for the character's abilities, the situation, etc. And in some situations, we'll want them directly contributing to the combat, where we'll want their size, effects, and details to be appropriate to the character. 

SCRPG is a very flexible and versatile system. If we start creating rules around how it needs to be consistent for things like this, I think we'll lose one of its greatest strengths. Having examples of how to do this would be great, though, so folks understand what's possible and how it might work, but I personally don't think an official system to manage it would be good. 

Doesn't stop us from discussing how it might work, though. :-D
