SCRPG Character Sheet (FF-PP)

I've played a number of different RPG systems, and I tend to be a bit obsessive about character sheets—especially digital ones. I've always preferred a clean print-out or a paperless version over eraser marks and my bad handwriting, so I've created and edited a number of form-fillable character sheets over the years. When I got my hands on the SCRPG sheet, I saw a few spots where I knew I could tweak and make some minor improvements.

And then before I knew it, I had overhauled the entire sheet.

So with all due respect to the folks at >G and Critical-Hits, at the link above is a new-and-improved version of the SCRPG form-fillable character sheet. My goal was to make the sheet as polished as I could, while also mimicking the Sentinels of Freedom and Daybreak sheets that have already been published. Here's a (non-exhaustive) list of the changes:

  • Corrected all field dimensions and alignments
  • Converted main font to Gill Sans Nova (available as part of Windows 10) and corrected embedding
  • Changed hero point checkboxes from circles to diamonds
  • Standardized font size for Powers, Qualities, and Ability names (no longer Auto)
  • Standardized Ability game text to two lines of 8pt font, with the option to customize using Rich Text Formatting
  • Renamed and reorganized fields for better ease of use / tabbing
  • Minor graphical changes
  • Fixed bugs (including some I created)

Along with the blank sheet, I've included two test runs I did to re-create Tachyon and Headlong as a proof-of-concept, and I think the results are pretty darn close to the real thing. That said, I'd love to hear feedback from the community if there are any further corrections or improvements I can make. Thanks for reading the wall of text, and enjoy!
