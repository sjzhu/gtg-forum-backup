I might have mis-typed in the chat, so I wanted to clarify here! This does in fact refer to chapters of the Core Rulebook, which is currently being refined and edited and laid out (which is quite an extensive process). The chapters are:

  1. Introduction
  2. Playing the Game
  3. Creating Heroes
  4. Running the Game
  5. The Bullpen <- (creating GM elements)
  6. Adventure Issues <- (2 premade adventures)
  7. The Archives <- (premade heroes/villains/minions/environments/etc)
