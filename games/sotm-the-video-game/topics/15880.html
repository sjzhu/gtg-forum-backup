Shuffles will always shuffle the same way if done at the same time.  Rewinding resets the RNG seed to ensure the same shuffle comes out.  That way, you can't cheat by repeatably rewinding until you get a good shuffle.

Now, if you were taking out a different instrument each time, that would cause different shuffles.  If it was the same one, you will always get the same shuffle, though.
