It took forever to install, but does that for everything it installs.  Seriously, half an hour after download before it was done processing and installing, Probably because it was installing it onto the SD card.  Then I had to do it again for the season pass.  It took probably an hour and a half to get the game ready to play.  But I wasn't watching it constantly.

Other than that it runs great, but once you start loading 10 or more cards as options to select it gets slow, but not bogged down slow, just have to wait 5 seconds.

I haven't tried multiplayer because I assume that will not go well, but I should try it.

Sound and video are good, I don't notice pixilation like some people, so I don't miss the HD, the resolution to screen size should be plenty good enough for this game unless you really notice that stuff.

The only time the slow down became bothersome was playing Bunker with Ammo Drop when Collapsed Hallway cleared an 18 minion Forced Deployment. The clearing of minions took probably 3-4 minutes, and Bunker's play phase was really slow, probably a 5-8 second delay (felt like 10) with 30 cards in hand.

 

UPDATE:

So Multiplayer went fine, I mean the game went terribly but it ran just fine, so that doesn't appear to be an issue at all, which is cool.
