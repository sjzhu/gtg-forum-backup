You can unlock a hero variant in multiplayer only if you are playing that hero.

You can unlock a villain variant multiplayer if you have met all the conditions. Note that means multiple people can unlock it, but those who haven't fulfilled all the conditions (e.g. have beaten another villain previously) won't get it.

Why? Because that's what we decided was reasonable. For instance, if I'm playing a random multiplayer game, and someone else is playing Bunker and uses all 3 mode cards, it doesn't really make sense (to me) that I should get G.I. Bunker.
