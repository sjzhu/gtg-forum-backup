Some are scripted (sort of), some are not.  The random seed at the start has been set up for some of them to give specific cards.  However, playing cards that mess with decks vs. not messing with decks will cause different cards to show up.  Right now every game, when replayed, starts with the same random seed, so if you take the exact same actions you will get exactly the same outcome.
