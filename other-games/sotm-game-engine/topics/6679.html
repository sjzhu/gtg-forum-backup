The general way to read cards with multiple steps is look for a Coma or a Period

 

If it is a coma, the steps happen simultaneously

 

If it is a period, then they happen sequentially.

 

SO with Entomb, Every thing is damgaed. After all the damge is delt, it checks to see if the destruction condition was met.
