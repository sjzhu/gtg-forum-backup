Since Daniel Lew's Sentinels randomizer is only available for androad, I've decided to make a randomizer for iOS.  You can get it here: (https://itunes.apple.com/us/app/sentinels-multiverse-randomizer/id791098197?mt=8&ign-mpt=uo%3D4)

The Randomizer uses a point based system to estimate difficulty levels. The system is similar to the SotM score system (http://x.gray.org/sentinels-of-the-multiverse-difficulty-scores.html), but uses a slightly different statistical model.

If you have any questions, comments, or suggestions, let me know.
