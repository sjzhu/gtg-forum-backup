Couldn't find an answer to this in an existing thread:

Under normal rules, a hero with multiple power uses in a single turn must select distinct powers to activate.  How do these rules apply to the Argent Adept?

If I have Drake's Pipes (activate perform text on two melody cards) can I activate the same melody card twice?  What if I have two copies of the same melody card in play (they are not limited)?

This came up recently (in a discussion in which I discovered that songs can be sung multiple times in the same turn, something I'd totally missed up till that point), and I think the conclusion was that because it specifies two different Melody cards, they must indeed be two different physical cards. However, if you happen to have two copies of the same card out, you can sing both of them because they're two different cards - they just happen to have the same name.

I'm pretty sure that's how it is, anyway ;).

Perform and acompany aren`t "powers". Drake pipes said - activate two DIFFERENT melody cards. So you cannot activate the same card with it, of course if you have two copies of the same card you can activate them both. About other music cards - you can activate them how many times you can - but remember you can use any power only once so you can use each instrument only once. That`s because using an instument is a power.
