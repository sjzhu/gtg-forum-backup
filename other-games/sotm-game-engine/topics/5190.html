If the card is not limited, you can have multiple copies played. You are still limited to one power per turn, and thus you can only choose one of those two to use. If you have the ability to use more than one power per turn, I’m not sure what would happen. The rules state that the same power cannot be used more than once per turn, so it depends on if a power with the same wording counts as being the same power or not. In one case, having multiple cards of the same name will still only allow the power to be used once; in the other case, having multiple cards of the same name will allow the power to be used as many times as you have cards (limited by the amount of powers you can use per turn).

No universes will end this time I promise

If you have two copies of Cleansing Downpour in play (which, incidentally, reads “Power: Each Hero regains 2 HP.”), you can use either “instance” of the power on your power phase, but in either case, the power will simply work as written (i.e., each hero will regain 2 HP). If for any reason you can use an additional power on your turn, you may opt to use both “instances” of the power on Cleansing Downpour since they come from different distinct cards.
