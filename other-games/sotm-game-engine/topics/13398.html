Pydro:

What's interesting though is that Summon Staff was changed so that if there are no Staves in the deck, the deck isn't shuffled.

"If there are no Staves in the deck, the deck isn't shuffled" was the bug that was fixed in version 1.4.1. Now, the deck is always shuffled.

We discussed with Christopher, and "shuffle the trash into the deck" should cause a shuffle even when the trash is empty. This will be fixed in an update.

Note: on the tabletop, if you don't know anything about the state of the deck, it makes no difference whether you shuffle in that case from an information POV.
