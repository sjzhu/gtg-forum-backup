OK, I think I've got it this time.  It took me a long time to figure out a proper method to do what, to a human, is an achingly simple thing -- given a stack of cards, figure out which ones are alternates of each other and only allow one of each alternate in the final stack.  I thought I had it figured out earlier in the day, but then I realized that my solution only worked if you included the base card in the group.  If you only wanted Young Legacy and Greatest Legacy but not Finest Legacy, for example, my early attempt fell on its face.

But now it should be working just like we all want, for any number of alts, and all in an automated way so that as future cards are added, I don't have to do a bunch of manual futzing to get it to work out.  Please do your best to poke holes in it, and I'll try to jump on any fixes.  I've saved the old code, so if it turns out that the new code is completely unacceptable for some reason, I can revert to the old stuff and you can all keep using that while I figure out where I went wrong with the new stuff.

I was confused by your question at first, because in its current state it does retain your settings.  When you click the "go" button, it posts all of your settings back to the page, and as long as you keep using that same page, you'll retain those settings (that's why, if you refresh the page after having made a selection, it will ask if you want to resubmit the form).  But you mean you want to save the options even if you close down the browser and come back to the page fresh some other time, don't you?  Easy to fix.  I changed it so that now the randomizer puts your options into the URL after you hit "go".  If you bookmark the page after having set some options (or copy/paste the URL so you can get to it later), you'll go back to the page as it was after you made the selections.  If you ever want to start from scratch, just hit the "reset page" link in the "options" section.  Let me know if this addresses what you want, or if I've misunderstood completely.

I forgot to mention earlier that I've also added all the ST heroes/villains/environments to be in the random rotation by default (you can always turn them off if you don't have ST).  Greatest Legacy is still off by default since he's not really coming until Vengeance.
