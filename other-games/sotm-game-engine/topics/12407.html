This was officially clarified for the App (sorry if I made it sound like it was known all along).

All on destruction effects happen at the same time, and you can choose the order. The effect on the card itself does not have to happen first.

However, you cannot stop the cards own effect from happening. So, If Haka tries to eat the Sonic Mine, he can put it under Savage Mana first, but that (i.e. the lack of text) cannot stop the card from triggering. The way the App handles this is to put it in a different "zone" to trigger, then puts in under Sonic Mine.

There are 4 main stages that changes to the app move through (and not necessarily in a linear way - we iterate at each stage quite a bit).

  1. Internal development & testing - completely private between Handelabra Games and GTG
  2. Alpha testing - this uses the text-based Mega Computer system, and has a small group of external testers.
  3. Beta testing - this is a version of the real game on iOS, Android & Steam, and has a larger group of external testers
  4. Public release

Each stage in fact has its own Trello boards =). We have quite a few for different parts of the project for internal use, and there's one each for Alpha and Beta. The only public board is SotM Known Issues, which we use to communicate info about major issues in released versions.
