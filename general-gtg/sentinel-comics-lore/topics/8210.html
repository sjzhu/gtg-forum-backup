Kingofsouls:

I'm al little lost. What is Destruction of Indines?

Devastation of Indines is a card game using the Battlecon system. (The first Battlecon game was War of Indines). It's a strategy game intended to emulate 2d fighting games like Streetfighter, set in the high-magitech fantasy world of Indines.

In Battlecon, characters simultaneously and secretly select their attack, which consists of a Base (a particular type of attack, e.g. a charge or a fireball) and a Style which modifies that attack. All (or almost all) characters have access to the same six Bases, plus their own unique Base, 5 Styles, a unique ability, and a Finisher. There are 30 characters in the base Devastation box, and they all feel different, so there should be a lot of replayability.

The post that announced the Legacy promo character is below. Strikers (which are an optional expansion element) are explained on the first page of that Kickstarter.

http://www.kickstarter.com/projects/level99games/battlecon-devastation-of-indines-a-dueling-card-ga/posts/380540
