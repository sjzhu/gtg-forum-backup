On this subject, >G...if you're going to be in Germany, you might see if you can get a chance to talk to the guy who runs Yucata.de - it's a pretty good (not spectacular, but certainly not bad for something that a hobbyist and his buddies do in their spare time) site which runs online implementations of various games.  I have no idea what the financial implications are for the game companies who license content to Yucata, but a fairly large number of them have done so (admittedly, with the exception of an outdated version of AEG's Thunderstone, these are virtually all single-box eurogames, which probably have a very different business model from an expandable card game).  I'm not saying it's definitely something you should do, it has a lot of the same issues as Vassal and thus you would have to think about where you want to go with it, but I think it's something that would be worth exploring in the vein of "free advertising".  If it doesn't work for SOTM itself, it might eventually work for Sentinels: Tactics on the same basis as it does for various other board games (I say this knowing nothing about how Tactics works, so it also might not work, I'm just throwing it out there).
