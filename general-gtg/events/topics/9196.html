We haven't had a game event in awhile, so here it is. The same rules as the first villain beatdown are in effect, with a couple of additions:

 

*After you create a hero team, you must use the same team against each of their nemses.

*If you win a game, we gain points equal to the villain's difficulty. Simply put your name in the column of the villain.

*If you win an advanced game, you get double the points. Put your name twice in that column.

*Losses still count as 1 point. Put you name in the loss column.

*Advance losses count as 2 points. Put your name twice in the loss column.

*If you can, post a session report here.

*If you don't have a nemesis for a hero, make one up with what you have. You still need to play a number of games equal to the number of heroes on the team.

*You only need to play 1 nemesis game for each hero.

*Iron Legacy only counts as 1 nemesis game. The game can be repeated for a second nemesis, but you still need to play a number of games equal to the number of heroes on the team.

*If a team wins every match against their nemeses, we get a bonus, and you can name your team. You can replay any losses.

 

All game can be submitted here.

 

You will have a full week for this event. The deadline is Monday, January 13, 2014, 11:59 PM CST.
