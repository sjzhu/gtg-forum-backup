Hey everyone!!!

I wanted to let you all know that, if you are attending Gen Con, you should definitely sign up for the event "Terror in Megalopolis". It is a Sentinel Comics LARP co-written by Chrisopher and Adam (who will be there!) and Phoenix Outlaw Productions, who will also be running the event. It is a brand-new system and story and it is going to be *amazing*. We are running 2, each of which has a limit of 35 players. I'm posting about it here not only because it will be amazing and I wanted to make sure all of you know, but also because it wasn't live when Gen Con tickets went on sale, so we have a lot of slots left! I also wanted to explain what "Terror in Megalopolis" means, since Gen Con prevented us from using a more logical and useful title like "Sentinel Comics LARP".

Anyhow, if you'll be at Gen Con, definitely sign up! It's worth it!
