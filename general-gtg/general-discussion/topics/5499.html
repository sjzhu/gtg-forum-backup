I was poking around the BBG forums and saw the hp tracker posted there that uses a dual spinner design (this one: http://www.boardgamegeek.com/filepage/75085/hp-tracker). I thought it was a clever design but I thought maybe I could add something to it, so I gave it a shot. The results are a new set of hp trackers which are small enough to fit inside a card box with each character’s cards. I’ve got a full set of heroes plus one for each villain.

They do not have the hero’s powers or anything on them, just the character’s starting hp total and the “play a card, use a power, draw a card” reminder text. So you couldn’t use these instead of the normal character cards from the game. But, these should eliminate the need to use dice (or whatever else) to track hero and villain hp and are easily portable in card boxes, so I think people may find them helpful.

I’ll post a link to the .zip file here and update my “Spiff’s SotM Accessories” post to include it there as well. As always, if you see anything wrong with the files, please let me know.

http://www.spiffworld.com/temp_files/sotm_small_hp_trackers.zip
