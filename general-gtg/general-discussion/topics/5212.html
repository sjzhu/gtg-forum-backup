It was a DOS fighting game engine made some time ago. It allows one to create characters, stages, and even alter the look and feel of the interface to basically create a fighting game. And each of these three are independent of each other, allowing you to create (and download) all you want. There are characters already made for most Capcom and MK games, they have Mario Bros characters, The Simpsons characters ( http://www.youtube.com/watch?v=jP7CfbpMmwk http://www.youtube.com/watch?v=rCVtII0FNGY http://www.youtube.com/watch?v=akG4BMuARxs http://www.youtube.com/watch?v=wFlWW2fWZq8 ), and almost anyone you can imagine. I used to play it quite a bit, but then I got tired of fighting games in general, and haven’t played in some time.

A Windows beta had been released, but afterwards the original company stopped development (I don’t think they even exist anymore). Recently there has been an attempt to create a new engine that works with all existing characters/stages/etc and runs on XNA (Windows, XBox, Windows Phone).
