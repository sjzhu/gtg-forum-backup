I just realized that I never actually got around to mentioning this here, uh, whoops. :>

After seeing how all the Sentinels news seemed to be scattered all over the place, I came up with the idea of finding some way to pull all the news from all the various sources into one place. And ended up creating a Discord server for that purpose:

https://discord.gg/YERzHyB

It's a listen-only server; no actual chatting. (We have the Handelabra server, RoD, and the LP server for that anyway!) It's split up into a bunch of different categories so you can easily mute any source of news you're not particularly interested in.

Fair warning that the news is not always right away; the Twitch aspect in particular has an annoying tendency to lag 48 minutes after the stream starts. So if you want stuff to be up-to-the-second you're best off following the source yourself. But it's good for casually following less time-sensitive news in one spot.
