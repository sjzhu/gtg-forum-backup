I originally posted this on BGG but thought a basic explanation of expansions and characters from the multiverse could be a useful tool for new players who come here seeking info. The main site has much of this info and much more for the core game but is still behind on updates for expansion info. I am hoping that once the website is updated then the info in this thread will be more readily available without searching the forums.

Sentinels of the Multiverse is a game and an experience. There is rich history to each character and overarching story arches that are being revealed little by little over time. This post is not meant to explain all those story elements, but is intended to help new players understand what the various sets contain in terms of characters and environments so as to better understand discussion seen in the forums.

As basic background for those unfamiliar with the game play, each character comes with their own unique deck of cards. Only one environment deck, one villain deck and 3 to 5 hero decks are played in a given game. The mixing and matching of characters in a game is what adds much of the variety to the game play. A character has a card (2 for villains) that represent them and their basic powers as well as a deck of cards. The environment is simply a deck of cards.

Contents of the various sets…

Core Game (1st Edition)
The first edition core game comes with 10 heroes, 4 villains and 4 environments.

Heroes: Absolute Zero, Bunker, Fanatic, Haka, Legacy, Ra, Tachyon, Tempest, The Visionary and The Wraith. (Note: references in the game to the Freedom Five refer to Legacy, Bunker, Tachyon, The Wraith and Absolute Zero who within the story realm of Sentinel Comics work together as a team)

Villains: Baron Blade, Citizen Dawn, Grand Warlord Voss, Omnitron

Environments: Megalopolis, Insula Primalis, Wagner Mars Base, Ruins of Atlantis

Young Legacy Promo
This promo was printed with the 1st Edition core game. It provides an alternate character card (Legacy’s daughter) to be played with the Legacy deck from the core game.

Core Game (2nd Edition)
The second printing contains the same heroes, villains, and environments as the first printing. But will be packaged in a bigger box to hold it and 2 expansions, include tokens to track health and modifiers, include dividers for organization, have some additional and updated card art, and be printed on sturdier card stock. While this is the new standard core edition, there is no change that would affect 1st Edition compatibility with all other promos and expansions because each deck is played independently.

Baron Blade Alternate Promo
This promo will be printed with the 2nd Edition of the core game. It provides alternate character cards (each villain has 2 character cards, one text and one pictures) of Baron Blade to be played with his deck from the core game.

Cosmic Omnitron Alternate Promo
This promo will be printed with the 2nd Edition of the core game. It provides alternate character cards (each villain has 2 character cards, one text and one pictures) of Omnitron to be played with his deck from the core game.

1st Expansion: Rook City
Rook city is the first expansion to the game. It includes 2 new heroes, 4 new villains and 2 new environments. Thus far this is the model >G is following for future expansions.

Heroes: Expatriatte, Mr. Fixer

Villains: Spite, The Matriarch, Plague Rate, The Chairman (with secondary The Operative character)

Environments: Rook City, Pike Industrial Plant

Rook City Wraith Alternate Promo
This promo was printed with the Rook City expansion. It provides an alternate character card of The Wraith to be played with her deck from the core game.

2nd Expansion: Infernal Relics
This expansion will be released in 2012. It will include 2 new heroes, 4 new villains and 2 new environments. Details are still forthcoming as the kickstarter campaign to launch this expansion is still running. As of this post we know…

Heroes: NightMist, The Argent Adept
Villains: GloomWeaver, Akash’bhuta, The Ennead, Apostate

Environments: Unknown, Unknown

Ra - Horus of Two Horizons Alternate Promo
This promo will be printed with the Infernal Relics expansion. It provides an alternate character card of Ra to be played with his deck from the core game.

Redeemer Fanatic Alternate Promo
This promo will be printed with the Infernal Relics expansion. It provides an alternate character card of Fanatic to be played with her deck from the core game.

Unity Promo Hero Character
This is a stand alone bonus hero, complete with deck, and is not part of any given expansion set and is available as an extra $5 pledge on the 2nd Edition/Infernal Relics Kickstarter campaign.

Ambuscade Promo Villain Character
This is a stand alone bonus villain, complete with deck, and is not part of any given expansion set and will be made available as a kickstarter bonus on the 2nd Edition/Infernal Relics Kickstarter campaign if it reaches $75K.
