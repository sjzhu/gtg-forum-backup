Looks like we’re talking about this: http://cgjennings.ca/eons/

I downloaded it and poked around a bit (it’s java, so works on Macs, which is refreshing). Looks like it’s a program that has templates for game items like cards which lets you customize them using the app’s interface. For example, you could make a new Investigator for the Arkham Horror game, and it has buttons to increase/decrease his stats or change his name/title, all of which updates right on the artwork, which you would then presumably print out. Seems pretty nice, especially if you don’t have access to a program like Photoshop, which should be able to do all the same things this app can do.

I guess if someone were to make a SotM plugin for the app, they’d create templates for the card types and then the app would let you fill in a character or villain’s hp and rules, or a card’s type (“minion”, “device”) rules and flavor text. Could be tough to get satisfactory results without new art for the custom cards. I suppose you could draw your own or use comic book art found on the Internet.
