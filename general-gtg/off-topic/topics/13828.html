This is a fairly irregular contest held by the scifi/fantasy book review website fantasyliterature.com.  The basic premise is that there are some books with really ugly/horrifying/bizarre covers, and we need to come up with titles for books that would actually match the cover.

 

The game is fun, so I thought I'd share it with all of you!  Here is the ongoing competition (mildly NSFW).  I've tried to come up with a name for this one, but I can't beat some of the ones already suggested.
