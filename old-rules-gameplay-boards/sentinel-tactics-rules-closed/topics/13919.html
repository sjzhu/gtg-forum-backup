Bolstering Team-Up lets Beacon take an action.  The action chosen will follow all normal rules.

Overwhelm says to select an action, not use it.  Each Proletariat takes that action.  You are not using the selected action, Overwhelm is giving you the effect of that action for each Proletariat.

 

That is the difference.
